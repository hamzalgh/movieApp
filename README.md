# Movie App

This is a movie application allows users to browse movies, search for specific titles, and view detailed information about each movie.

## Features

- **Movie Browsing:** Discover movies with categories and filters.
- **Search Functionality:** Search for movies by title.
- **Movie Details:** View detailed information about a selected movie, including **related** and **similar** movies.
- **Responsive Design:** Optimized for various screen sizes.

## Note

This is the **frontend-only version** of the application. Future updates may include a backend and database integration to enhance functionality.

## Tech Stack

- **React**: Frontend library for building the user interface.
- **Vite**: Fast development server and build tool.
- **Redux Toolkit**: State management for handling movies and categories.
- **Tailwind CSS**: Utility-first CSS framework for styling.

## Getting Started

1. Clone the repository:
   ```bash
   git clone <repository-url>
2. Navigate to the project directory:
   ```bash
   cd movieApp
3. Create .env file with TMDB API:
   ```bash
   VITE_API_KEY=your_api_key_here
4. Install dependencies:
   ```bash
   npm install
5. Start the development server:
   ```bash
   npm run dev
